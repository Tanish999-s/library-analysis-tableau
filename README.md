# 📚 Library Book Analysis Dashboard — Tableau

A data visualization project built with **Tableau** that analyzes a library's book collection — tracking total copies, available copies, issued books and publisher-wise distribution through interactive charts and a combined dashboard.

![Tool](https://img.shields.io/badge/Tool-Tableau-E97627?style=for-the-badge&logo=tableau&logoColor=white)
![Type](https://img.shields.io/badge/Type-Data%20Visualization-blue?style=for-the-badge)

## 📊 Dataset Overview
The dataset contains **10 books** (published 2017–2022) with these fields:

| Field | Description |
|---|---|
| Book ID | Unique ID of the book |
| Title | Name of the book |
| Author | Book author |
| Genre | Data Science, ML, Programming, Statistics... |
| Publisher | Publishing house |
| Year Published | 2017 – 2022 |
| Total Copies | Total copies owned by the library |
| Copies Available | Copies currently on shelf |
| Issued Count | How many times the book was issued |

## 📈 Key Insights
- 📚 **140 total copies** in the library collection, **105 currently available**
- 🔄 **590 total issues** recorded across all books
- 🏆 **Most issued book:** *Statistics 101* (90 issues), followed by *Database Management* (80) and *Python Programming* (75)
- 🏢 **Top publisher by copies:** StatWorld (25 copies), then MLHouse (20 copies)
- 💡 Tech books (Statistics, Python, ML) are clearly the most in-demand among readers

## 📑 Worksheets & Dashboard
1. **No. Of Copies Available** — availability of copies per book
2. **No. Of Copies Available According to Publisher** — publisher-wise copy distribution
3. **TOTAL NO. OF COPIES** — total copies overview
4. **Dashboard 1** — all worksheets combined into one interactive dashboard

## 🚀 How to View
This is a packaged Tableau workbook (`.twbx`) — data is embedded inside the file, so no external setup is needed:
1. Download `PROJECT 2.twbx`
2. Open it with [Tableau Public](https://public.tableau.com/en-us/s/download) (free) or Tableau Desktop
3. Explore the worksheets and dashboard
